game-event-calendar / タブ右下・下段修正 v6

今回の原因
==============================

1. 原神タブ右下のはみ出し

タブ高さは32pxなのに、
外枠が24px地点から始まっていたため、
タブ右辺(frame-chip-game-6)が8pxだけ外枠内へ
突き出していました。

今回は

タブ下端 = 32px
外枠上端 = 32px

にして、Y座標を完全一致させています。

画像を作り直す必要はありません。


2. 外枠下段のズレ

GitHub上の frame-chip-game-8.png を確認すると、
frame-chip-game-2.png と同じ向きで、
横線が画像の上側にあります。

7・8・9を下段に並べると、
8だけ線の高さが上へズレて見える原因になります。

今回は frame-chip-game-8 だけ
CSSの scaleY(-1) で上下反転して、
下辺として使うようにしました。

素材側で直す場合は、
frame-chip-game-8.png を上下反転した画像に
差し替えれば同じ結果になります。


差し替えるファイル
==============================

index.html
style.css
script.js
