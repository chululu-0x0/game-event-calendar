game-event-calendar / minidot table frames v14

今回の修正
==============================
v13 で崩れていた点を、まず以下の方向で修正しました。

1. フレームの縦長化
------------------------------
原因:
- pixel-frame-table に height:100% 相当の使い方が残っていて、
  内容量以上に縦へ伸びていた

対応:
- ゲーム外枠 / イベント内枠 / 仮パネルは
  content基準の auto height に戻した
- event-row や icon サイズも少し詰めた


2. ゲームタブと外枠の接合
------------------------------
方針:
- タブは下辺なし（7〜9なし）
- メイン外枠の上にタブテーブルを重ねる
- 左端は完全一致
- 重なり量は 2px

つまり、ユーザー案にかなり近い構成です。

見た目イメージ:
  [タブ]
   └(下辺なし)
  [外枠]
  上辺へ2px重ねる

これで、タブ下辺を消しつつ、
外枠との間に隙間が出にくい構造にしています。


3. minidot-8 の使い方
------------------------------
通常フレーム:
  8px素材 → 16px表示（2倍）

詳細フレームのみ:
  8px素材 → 32px表示（4倍）


確認してほしい点
==============================
- ゲームごとの外枠が縦に伸びすぎていないか
- 「原神」タブと外枠の接合が前より自然か
- イベント一覧の情報量が詰まりすぎていないか

まだ細かい座標や余白は微調整の余地がありますが、
今回はまず構造を安定側へ戻す修正版です。
