URL取得について
==============================
静的なGitHub Pages上で動くため、
取得先サイトがブラウザからの外部アクセス(CORS)を許可している必要があります。

MediaWiki系の /wiki/ URL は、可能な場合 api.php + origin=* を自動で試します。
それ以外は通常fetchを試します。

取得先側がCORSを禁止している場合は、
URLだけでは直接取得できません。その場合は将来的に
Supabase Edge Function等の取得用バックエンドを挟むと安定します。
