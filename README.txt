game-event-calendar / frame-tab-active-a 32px 等倍修正版 v9

今回の修正
==============================

GitHub上の現在の状態では、

--slice-tab: 32px

になっている一方で、

.top-tab {
  height: 32px;
}

のままでした。

9スライスは縦方向に
「上32px + 中央 + 下32px」
が必要なので、ボタン全体32pxでは等倍表示できず、
ブラウザ側で縮小・圧縮が発生します。

そのため今回は以下へ修正しています。


1. 上段タブ画像
==============================

frame-tab-active-a1.png ～ a9.png

を使用。


2. タブ用パーツ
==============================

--slice-tab: 32px;

画像自体が32x32pxなので等倍です。


3. ボタン全体の高さ
==============================

.top-tab {
  height: 80px;
}

内訳は、

上辺 32px
中央 16px
下辺 32px

です。

これで9分割画像を縦方向にも縮小せず表示できます。


4. 横線・縦線のぼけ対策
==============================

以前:

background-size: auto 100%;

今回は:

background-size: 32px 32px;

へ変更。

横辺2/8、縦辺4/6、中央5のすべてを
32x32pxの整数サイズで繰り返します。

ブラウザに縦横サイズの自動計算をさせないことで、
repeat部分の再サンプリングをできるだけ避けます。


5. スマホ側
==============================

@media(max-width:420px) 側でも

--slice-tab:32px;
top-tab height:80px;

を維持するようにしています。

PCでは32pxなのにスマホだけ8pxや16pxへ戻る、
という状態を防ぎます。


注意
==============================

32px素材を完全等倍で9スライスする場合、
上下だけで64px必要です。

そのため以前の32px高の細いボタンと、
「32px画像を完全等倍」の両立はできません。

見た目を再び細くしたい場合は、
素材自体を16px版などに作るか、
上下パーツだけ16px表示へ縮小する必要があります。
