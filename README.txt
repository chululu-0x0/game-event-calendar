game-event-calendar / minidot table frames v15

今回の修正
==============================

v14で下方向へフレームが異常に伸びていた原因を修正しました。

原因
==============================

縦辺（4 / 6）を実画像で並べるために、

.pf-strip-y

の中へ大量の16px画像を縦に並べていました。

その画像列が、見た目だけでなくtableの高さ計算にも参加してしまい、
イベントが2件しかなくてもフレーム全体が1000px前後まで
引き伸ばされる状態になっていました。

v15では縦辺画像列を position:absolute にしています。

これにより、

- 縦辺画像はセル内に見える
- 余った部分はoverflow:hiddenで切れる
- 画像列自体はtableの高さを押し広げない

という状態になります。


ゲーム名タブ
==============================

タブは完全に

1 2 3
4 5 6

だけ使用します。

7 / 8 / 9 は使いません。

高さ:
24px

本体開始:
22px

なので、

24 - 22 = 2px

だけ外枠へ重なります。

左端も同じx=0で揃えています。


通常フレーム
==============================

minidot-8-1～9
8px素材 → 16px表示（2倍）

イベント詳細だけ:
8px素材 → 32px表示（4倍）

今回も枠線は実imgタイル方式です。


確認ポイント
==============================

1. 原神などの外枠がイベント内容ぶんの高さで終わるか
2. 内側イベント枠も下へ伸び続けないか
3. ゲーム名タブが以前より短く見えるか
4. タブと外枠が2pxだけ重なって自然に接続しているか
