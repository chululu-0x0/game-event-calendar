今回の変更
==============================
フレームとして使っていた部分を、可能な限り HTML table + 実imgタイル方式へ統一しました。

==============================

通常フレーム
==============================
元画像 8px → CSS表示 16px（2倍）

対象:
- 上段「開催中 / イベントカレンダー」
- ゲーム名タブ
- ゲームごとの外枠
- イベント一覧の内枠
- お気に入り / 設定の仮パネル

イベント詳細
==============================
サイドから出る詳細シートだけ
元画像 8px → CSS表示 32px（4倍）

ぼけ対策
==============================
枠線になる 1,2,3,4,6,7,8,9 は background-repeat ではなく
実際の <img> を横/縦へ複数並べています。

余った部分は画像を縮小せず overflow:hidden で切っています。

中央の 5 は「面」なので、DOM肥大化を避けるため背景タイルとして使用しています。
枠線そのものはすべて実img方式です。

レイアウト
==============================
これまでの画面構成をなるべく維持しながら、
余白・イベント行・フレーム間隔を少し詰めて、
全体をまとまりよくしています。
