game-event-calendar / タブ一体化調整 v4

今回の変更
==============================

1. frame-chip-game のタブは 8px 原寸で使用
2. ゲーム名タブは 1〜6 だけ使用
   1 2 3
   4 5 6

   7 8 9 は使わず、下辺を開放しています。

3. ゲーム外枠は frame-chip-game 1〜9 を使用
4. ただし「タブと外枠が接する上辺」は、
   frame-chip-game-5 の面で上辺を消してあります。

見た目の構造
==============================

     ┌── 原神 ──
     │
     └──────────────┐
       ┌──────────┐ │
       │ イベント1 │ │
       │----------│ │
       │ イベント2 │ │
       └──────────┘ │
     └───────────────┘

つまり、
- タブ下辺なし
- タブ直下の外枠上辺なし
なので、スケッチのように
「タブから外枠がそのまま伸びている」形を狙っています。

内側には frame-card-event-1〜9 を8px原寸で置き、
その中にイベント一覧を表示します。
