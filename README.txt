game-event-calendar / タブ左辺固定 v5

今回の調整
==============================

添付スクリーンショットで見えていた、

- ゲーム名タブの左辺
- ゲーム外枠の左辺
- タブ直下の接続部分

の3つをすべて x = 0 に固定しました。

これまではタブだけ left: 8px だったため、
外枠より一段内側へ入って見えていました。


8pxグリッド化
==============================

frame-chip-game は8x8素材なので、
接続部分も8px単位へ揃えています。

- タブ高さ: 32px
- 外枠との重なり: 8px
- 上余白: 24px
- タブ横幅: 8px単位へ切り上げ

34pxのような素材サイズと噛み合わない高さをやめています。


外枠下段
==============================

frame-chip-game-7 / 8 / 9 が入る最下段も
8px高へ明示固定し、外枠全体を width:100% に固定しました。

これで上辺・左右・下辺が同じ8px座標系を使います。


差し替えるファイル
==============================

index.html
style.css
script.js

画像素材はGitHub上のものをそのまま使用します。
