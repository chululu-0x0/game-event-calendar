game-event-calendar / minidot table frames v18

今回の修正
==============================
1. 一覧を上げたことで出ていたゲームタブ右下のはみ出しを調整
2. 上段「開催中 / イベントカレンダー」ボタンの下辺が見えるよう、高さを少し戻した
3. メインフレーム内の内側イベント一覧フレームをさらに大きく
4. ゲームタイトル文字を大きくし、タブ中央へ配置
5. ゲームタイトル文字数に応じてタブ幅が変わる仕組みを追加
6. 進行度バーを「開始時MAX → 日付経過で減少」へ変更
7. 進行度バーは残り割合に応じて色が変化
   - 高: 青
   - 中: ピンク
   - 低: オレンジ

補足
==============================
上段ボタンの下部分は画像を使っています。
今回の問題は「画像を使っていない」のではなく、
高さが詰まりすぎて下辺16pxぶんが見えにくくなっていた可能性が高いです。
そのため v18 では top-tab の高さを少し戻しています。

確認ポイント
==============================
- ゲームタブ右下のはみ出しが収まったか
- 上段ボタンの下辺が表示されているか
- ゲームタイトルが中央寄せ・少し大きめになっているか
- タイトル文字数に応じてタブ幅が変わるか
- 進行度バーが日付経過に応じて減少し、色が変わるか
